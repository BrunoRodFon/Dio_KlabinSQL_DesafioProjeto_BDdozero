# 🔧 Projeto Banco de Dados – Oficina

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio da DIO com o objetivo de criar, do zero, o esquema lógico de um banco de dados para o cenário de uma oficina.

O projeto contempla:

- Modelagem do esquema lógico a partir do modelo conceitual (ER)
- Definição de chaves primárias e estrangeiras
- Aplicação de constraints
- Criação do script SQL do banco de dados
- Inserção de dados para testes
- Desenvolvimento de consultas SQL

---

## 🏗️ Etapas Realizadas

- Criação do modelo relacional
- Implementação do banco via Script SQL
- Persistência de dados
- Elaboração de queries com diferentes níveis de complexidade

---

## 🔎 Consultas SQL

As consultas desenvolvidas incluem:

- SELECT simples
- Filtros com WHERE
- Atributos derivados
- Ordenações com ORDER BY
- Agrupamentos com HAVING
- Junções entre tabelas (JOIN)

---

## 🚀 Como Executar

1. Execute o script de criação do banco de dados
2. Execute o script de inserção de dados
3. Execute o script contendo as consultas SQL

---

Projeto desenvolvido para fins educacionais como parte do desafio da DIO.
